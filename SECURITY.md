# Security policy

SGD3DGS App is early-stage software intended to run locally or on a trusted team
machine. The API skeleton binds to `127.0.0.1` by default and provides no
authentication. Do not expose it directly to the public internet.

Do not commit private captures, credentials, access tokens, signed model URLs,
or personal data. Treat indoor scans as potentially sensitive data.

For a suspected vulnerability, contact the repository owner privately through
their GitHub profile rather than opening a public issue. Replace this paragraph
with a dedicated security contact after publishing the repository.
